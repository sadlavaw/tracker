# Бот-«входящие» для трекера

Пишешь боту заметку и нажимаешь кнопку — запись попадает в приложение.

- `приготовить еду` → **Сегодня / Завтра / Скоро / Долго** — станет задачей
- `12 кофе`, `кофе 12,5€`, `1 200 аренда` → **Расходы** — станет расходом (категория «Другое»)

Заметки пишутся по очереди: написал — нажал кнопку, написал — нажал. Если написать
несколько заметок подряд, кнопки применяются к ним **в порядке написания**; в ответе бот
показывает, к какой заметке применил кнопку, и сколько ещё не разобрано.
Бот отвечает только на кнопку (подтверждением), на саму заметку молчит.

Записи лежат на сервере, пока ты не откроешь приложение: оно забирает их при запуске
и при возврате в него, затем подтверждает получение, и сервер их удаляет.

Команды: `/start` (показать кнопки), `/clear` (удалить неразобранные заметки).

## Что понадобится
- Node.js 18 или новее (`node -v`)
- Бесплатный аккаунт Cloudflare
- Токен бота из @BotFather

## Развёртывание (один раз)

Все команды — из папки `bot` этого репозитория.

1. Вход в Cloudflare (откроется браузер):
   ```
   npx wrangler login
   ```
2. Создать базу и **скопировать `database_id` из вывода в `wrangler.toml`**:
   ```
   npx wrangler d1 create tracker
   ```
3. Создать таблицы:
   ```
   npx wrangler d1 execute tracker --remote --file=schema.sql
   ```
4. Задеплоить. В конце команда напечатает адрес вида `https://tracker-bot.<твой-поддомен>.workers.dev`:
   ```
   npx wrangler deploy
   ```
5. Записать секреты (вставь значения, когда спросит; в репозиторий они не попадают):
   ```
   npx wrangler secret put BOT_TOKEN
   npx wrangler secret put WEBHOOK_SECRET
   ```
   `WEBHOOK_SECRET` придумай сам: случайные буквы и цифры (можно `_` и `-`), 20+ символов.
6. Подключить бота к Worker. Открой в браузере (подставь свой адрес и секрет):
   ```
   https://tracker-bot.<поддомен>.workers.dev/setup?key=<WEBHOOK_SECRET>
   ```
   В ответе должно быть `"ok":true`.
7. Напиши боту любое сообщение — он ответит `Твой Telegram ID: 123456789`.
8. В `wrangler.toml` впиши это число в `OWNER_ID = "123456789"` и задеплой ещё раз:
   ```
   npx wrangler deploy
   ```
9. Напиши боту `/start` — появятся кнопки. Проверь: `купить хлеб` → «Сегодня».
10. Пришли адрес Worker (из шага 4) — его нужно вписать в приложение (`API_URL` в `index.html`).

## Безопасность
- Бот отвечает и принимает записи **только** от `OWNER_ID`. API для приложения проверяет
  подпись Telegram (`initData`) и тот же `OWNER_ID`; подпись действует 7 дней.
- Токен бота и `WEBHOOK_SECRET` хранятся только в секретах Cloudflare. Если токен утёк:
  в @BotFather `/revoke`, затем снова `npx wrangler secret put BOT_TOKEN`.
- Текст заметок временно хранится в базе Cloudflare D1, пока приложение их не заберёт.

## Если что-то не работает
- Логи Worker в реальном времени: `npx wrangler tail`
- Состояние webhook: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo` (открывай только сам: в адресе токен)
- Кнопки не появились — отправь `/start`.
- Кнопки слишком мелкие — раскладку можно изменить в `KEYBOARD` в `worker.js`.
